# Типография «Кристалл Принт» — cristalprint.ru

Статический сайт типографии. Публикуется на Vercel (https://cristal-print.vercel.app) — каждый push в main выкладывается автоматически.

Сайт собирается скриптом `build.py` из исходников (контент — `content.py`, стили и скрипты — `static/`).
Править HTML в этом репозитории вручную не нужно: изменения вносятся в исходники и сайт пересобирается.

- `api/lead.js` — приём заявок с сайта в Telegram (серверная функция Vercel; ключи — в Environment Variables проекта).
