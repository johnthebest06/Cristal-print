# Типография «Кристалл Принт» — cristalprint.ru

Статический сайт типографии. Публикуется через GitHub Pages.

Сайт собирается скриптом `build.py` из исходников (контент — `content.py`, стили и скрипты — `static/`).
Править HTML в этом репозитории вручную не нужно: изменения вносятся в исходники и сайт пересобирается.

- `api/lead.js` — приём заявок с сайта в Telegram (серверная функция Vercel, на GitHub Pages не выполняется).
